# Dashboard artwork

- valley-header.webp: generated decorative tropical landscape for the app header.
- neighbourhood-illustration.webp: generated fictional neighbourhood map illustration with no
  report markers, coordinates, recycling sites or data. The UI always labels it as illustration.
- Both images generated on 30 October 2026 with the built-in image generation tool. Original
  generated PNGs remain in the generation output; project assets are WebP-encoded at quality 90
  for packaging. React Native crops responsively using resizeMode=cover.
- Prompts requested no text, logos, device chrome or real geographic location. Palette is
  forest green, sage and ivory, guided by the client's reference in INNOVATION EVA 410.pdf.
- ../branding/ecoxene-client-logo.jpeg: original embedded logo extracted from client PDF page 1;
  no logo redesign. Existing native launcher artwork is unchanged in this dashboard-only update.
